# 功能与注意事项

### 1. 绝对值与符号

| 函数 | 功能 | 数学公式 | 示例 | 注意事项 |
|------|------|---------|------|---------|
| `fabs(x)` | 返回浮点数 x 的绝对值，去掉符号位。对 `-0.0` 返回 `+0.0`，对 `NaN` 返回 `NaN` | \|x\| | `fabs(-3.5) = 3.5` | 仅用于浮点；整数用 `abs`/`labs`/`llabs` |
| `copysign(x, y)` | 返回大小等于 x、符号等于 y 的数，正确处理 `±0.0`、`NaN`、`Inf` | \|x\|·sign(y) | `copysign(3, -1) = -3` | 不是简单相乘；编译器通常内联为几条基础指令 |
| `signbit(x)` | 判断符号位是否为负，返回非零表示负。能区分 `-0.0` 和 `+0.0` | — | `signbit(-0.0) = 1` | 不触发浮点异常；与 `x < 0` 不同 |

### 2. 取模与余数

| 函数 | 功能 | 数学公式 | 示例 | 注意事项 |
|------|------|---------|------|---------|
| `fmod(x, y)` | 计算 x 除以 y 的浮点余数，结果符号与 x 相同，大小小于 \|y\| | x - trunc(x/y)·y | `fmod(5.3, 2) = 1.3` | glibc 新算法用位操作替代除法；热路径避免 |
| `remainder(x, y)` | IEEE 754 余数，用就近取整，结果符号可不同于 x | x - round(x/y)·y | `remainder(5.3, 2) = -0.7` | 比 `fmod` 更慢；结果在 `[-|y|/2, \|y\|/2]` 内 |
| `remquo(x, y, &q)` | 返回余数 + 商的低位（至少低 3 位） | 同 `remainder`，q 存商 | `remquo(5.3, 2, &q)` → q=3 | q 只保证低几位正确，不能当完整商用 |

### 3. 融合乘加

| 函数 | 功能 | 数学公式 | 示例 | 注意事项 |
|------|------|---------|------|---------|
| `fma(a, b, c)` | 计算 `a*b + c`，中间乘积不截断，以无限精度计算后只舍入一次。比 `a*b+c` 精度更高 | a·b + c | `fma(2, 3, 4) = 10` | ARM32 早期 VFPv3 无 FMA，回退 libm；ARM64 基础指令无需扩展；x86 需 CPU 支持 FMA3 |

### 4. 最值与差值

| 函数 | 功能 | 数学公式 | 示例 | 注意事项 |
|------|------|---------|------|---------|
| `fmax(x, y)` | 返回较大者，NaN 时返回另一个 | max(x, y) | `fmax(3, 5) = 5` | x86 `MAXSS` 的 NaN 语义与 C 标准不一致，需编译器额外处理 |
| `fmin(x, y)` | 返回较小者，NaN 时返回另一个 | min(x, y) | `fmin(3, 5) = 3` | NaN 语义同 `fmax`，x86 需编译器修正 |
| `fdim(x, y)` | 返回 x - y 的正部分，否则返回 `+0.0` | max(x-y, 0) | `fdim(5, 3) = 2` | 结果是 `+0.0` 而非 `-0.0` |

### 5. 指数与对数

| 函数 | 功能 | 数学公式 | 示例 | 注意事项 |
|------|------|---------|------|---------|
| `exp(x)` | 计算 e 的 x 次幂 | eˣ | `exp(1) = 2.718...` | x 大时溢出返回 `+Inf`；ARM64 可用 SLEEF 向量化 |
| `exp2(x)` | 计算 2 的 x 次幂 | 2ˣ | `exp2(3) = 8` | 比 `pow(2,x)` 快得多 |
| `expm1(x)` | 计算 eˣ - 1，x 接近 0 时精度高 | eˣ - 1 | `expm1(1e-10) ≈ 1e-10` | 避免 `exp(x)-1` 在小 x 时丢失有效位 |
| `log(x)` | 自然对数 ln(x)，x > 0 | ln x | `log(e) = 1` | x ≤ 0 返回 `NaN`/-Inf |
| `log10(x)` | 以 10 为底的对数 | log₁₀ x | `log10(100) = 2` | 卫星 CNR 计算常用 |
| `log2(x)` | 以 2 为底的对数 | log₂ x | `log2(8) = 3` | 比 `log(x)/log(2)` 快 |
| `log1p(x)` | 计算 ln(1+x)，x 接近 0 时精度高 | ln(1+x) | `log1p(1e-10) ≈ 1e-10` | 避免 `1+x` 在小 x 时丢失精度 |

### 6. 幂与根

| 函数 | 功能 | 数学公式 | 示例 | 注意事项 |
|------|------|---------|------|---------|
| `pow(x, y)` | 计算 x 的 y 次幂，支持任意实数指数 | xʸ | `pow(2, 10) = 1024` | 非常慢；整数幂用连乘或 `exp2`/`log2` 组合 |
| `sqrt(x)` | 计算平方根，x ≥ 0 | √x | `sqrt(16) = 4` | ARM64 延迟随输入变化；x < 0 返回 `NaN` |
| `cbrt(x)` | 计算立方根，支持负数 | ∛x | `cbrt(27) = 3` | 比 `pow(x, 1.0/3)` 快且精度高 |
| `hypot(x, y)` | 计算欧几里得范数 √(x²+y²)，避免中间溢出/下溢 | √(x²+y²) | `hypot(3, 4) = 5` | 直接 `sqrt(x*x+y*y)` 在 x、y 很大时会溢出 |

### 7. 三角函数

| 函数 | 功能 | 数学公式 | 示例 | 注意事项 |
|------|------|---------|------|---------|
| `sin(x)` | 计算正弦，x 为弧度 | sin x | `sin(π/2) = 1` | 范围缩减是主要开销 |
| `cos(x)` | 计算余弦，x 为弧度 | cos x | `cos(0) = 1` | 与 sin 合用 `sincos` 省一次范围缩减 |
| `tan(x)` | 计算正切，x 为弧度 | sin/cos | `tan(π/4) = 1` | x 接近 π/2 + kπ 时结果趋于 ±Inf |
| `asin(x)` | 反正弦，返回 `[-π/2, π/2]` | arcsin x | `asin(1) = π/2` | \|x\| > 1 返回 `NaN` |
| `acos(x)` | 反余弦，返回 `[0, π]` | arccos x | `acos(1) = 0` | \|x\| > 1 返回 `NaN` |
| `atan(x)` | 反正切，返回 `(-π/2, π/2)` | arctan x | `atan(1) = π/4` | 全域定义 |
| `atan2(y, x)` | 四象限反正切，返回 `(-π, π]` | arctan(y/x) + 象限 | `atan2(1, 1) = π/4` | 处理 x=0；比 `atan` 慢 |

### 8. 双曲函数

| 函数 | 功能 | 数学公式 | 示例 | 注意事项 |
|------|------|---------|------|---------|
| `sinh(x)` | 双曲正弦 | (eˣ-e⁻ˣ)/2 | `sinh(1) ≈ 1.175` | 大 \|x\| 时溢出；奇函数 |
| `cosh(x)` | 双曲余弦 | (eˣ+e⁻ˣ)/2 | `cosh(0) = 1` | 大 \|x\| 时溢出；偶函数 |
| `tanh(x)` | 双曲正切 | sinh/cosh | `tanh(0) = 0` | 大 \|x\| 时趋近 ±1，不溢出 |
| `asinh(x)` | 反双曲正弦 | ln(x+√(x²+1)) | `asinh(0) = 0` | 全域定义 |
| `acosh(x)` | 反双曲余弦 | ln(x+√(x²-1)) | `acosh(1) = 0` | x < 1 返回 `NaN` |
| `atanh(x)` | 反双曲正切 | ½ln((1+x)/(1-x)) | `atanh(0) = 0` | \|x\| ≥ 1 返回 `NaN`/`±Inf` |

### 9. 特殊函数

| 函数 | 功能 | 数学公式 | 示例 | 注意事项 |
|------|------|---------|------|---------|
| `erf(x)` | 误差函数 | (2/√π)∫₀ˣ e⁻ᵗ² dt | `erf(0) = 0` | 奇函数；概率、统计常用 |
| `erfc(x)` | 互补误差函数 1 - erf(x) | 1 - erf(x) | `erfc(0) = 1` | 大 x 时比 `1-erf(x)` 精度高 |
| `tgamma(x)` | 伽马函数 Γ(x) | ∫₀^∞ tˣ⁻¹e⁻ᵗ dt | `tgamma(5) = 24` | x 为非正整数时极值；大 x 溢出 |
| `lgamma(x)` | 计算 ln\|Γ(x)\| | ln\|Γ(x)\| | `lgamma(5) = ln24` | 避免 Γ 溢出；符号需另查 |

### 10. 取整

| 函数 | 功能 | 数学公式 | 示例 | 注意事项 |
|------|------|---------|------|---------|
| `ceil(x)` | 向上取整 | ⌈x⌉ | `ceil(1.2) = 2` | 结果仍为浮点 |
| `floor(x)` | 向下取整 | ⌊x⌋ | `floor(1.8) = 1` | 负数向 -∞，与 `trunc` 不同 |
| `trunc(x)` | 向零取整 | trunc(x) | `trunc(-1.8) = -1` | 与 `floor` 在负数时不同 |
| `round(x)` | 四舍五入，半整数远离 0 | round(x) | `round(1.5) = 2` | x86 的 ROUND 不支持 ties-away，需额外处理 |
| `nearbyint(x)` | 就近取整，当前舍入模式 | 就近整数 | `nearbyint(1.5) = 2` | 不触发 inexact 异常 |
| `rint(x)` | 同 `nearbyint`，可能触发 inexact | 就近整数 | `rint(1.5) = 2` | 可能触发 inexact 异常 |

### 11. 浮点分解与操作

| 函数 | 功能 | 数学公式 | 示例 | 注意事项 |
|------|------|---------|------|---------|
| `frexp(x, &e)` | 分解为 m·2ᵉ，m∈[0.5,1) | x = m·2ᵉ | `frexp(8, &e)` → m=0.5, e=4 | 与 `ldexp` 互逆 |
| `ldexp(x, e)` | x·2ᵉ | x·2ᵉ | `ldexp(0.5, 4) = 8` | 比 `x * pow(2, e)` 快 |
| `modf(x, &ip)` | 拆整数/小数部分 | x = ip + fp | `modf(3.7, &ip)` → ip=3.0 | ip 和返回值符号同 x |
| `scalbn(x, n)` | x·2ⁿ | x·2ⁿ | `scalbn(1, 10) = 1024` | 与 `ldexp` 类似 |
| `ilogb(x)` | 提取指数，返回 int | ⌊log₂\|x\|⌋ | `ilogb(8) = 3` | 返回 `int`；x=0 返回 `FP_ILOGB0` |
| `logb(x)` | 提取指数，返回浮点 | ⌊log₂\|x\|⌋ | `logb(8) = 3.0` | 返回 `double` |

### 12. 次一可表示值

| 函数 | 功能 | 数学公式 | 示例 | 注意事项 |
|------|------|---------|------|---------|
| `nextafter(x, y)` | x 朝 y 的下一可表示值 | — | `nextafter(1, 2) > 1` | 用于 ULP 步进、精度测试 |
| `nextup(x)` | x 朝 +∞ 的下一值 | — | `nextup(1) > 1` | C99 起；比 `nextafter(x, +Inf)` 直观 |

### 13. NaN 生成

| 函数 | 功能 | 数学公式 | 示例 | 注意事项 |
|------|------|---------|------|---------|
| `nan(s)` | 生成 quiet NaN，可指定 payload | — | `nan("")` | payload 实现定义；用于测试 NaN 传播 |

### 14. 分类与判断

| 函数 | 功能 | 数学公式 | 示例 | 注意事项 |
|------|------|---------|------|---------|
| `fpclassify(x)` | 浮点分类 | — | 返回 `FP_NAN` 等 | 返回宏常量 |
| `isfinite(x)` | 是否有限 | — | `isfinite(1.0) = 1` | 排除 Inf/NaN |
| `isinf(x)` | 是否无穷 | — | `isinf(1.0/0.0) = 1` | 返回非零，不区分正负 |
| `isnan(x)` | 是否 NaN | — | `isnan(0.0/0.0) = 1` | 返回非零 |
| `isnormal(x)` | 是否规格化 | — | `isnormal(1.0) = 1` | 次正规数返回 0 |
| `signbit(x)` | 符号位判断 | — | `signbit(-0.0) = 1` | 含 -0 |

### 15. 比较（不触发异常）

| 函数 | 功能 | 数学公式 | 示例 | 注意事项 |
|------|------|---------|------|---------|
| `isgreater(x, y)` | x > y，NaN 返回 0 | x > y | `isgreater(2, 1) = 1` | 不触发浮点异常 |
| `isgreaterequal(x, y)` | x ≥ y，NaN 返回 0 | x ≥ y | `isgreaterequal(1, 1) = 1` | 同上 |
| `isless(x, y)` | x < y，NaN 返回 0 | x < y | `isless(1, 2) = 1` | 同上 |
| `islessequal(x, y)` | x ≤ y，NaN 返回 0 | x ≤ y | `islessequal(1, 1) = 1` | 同上 |
| `islessgreater(x, y)` | x ≠ y，NaN 返回 0 | x ≠ y | `islessgreater(1, 2) = 1` | 等价于 `x < y \|\| x > y` |
| `isunordered(x, y)` | 是否无序（任一 NaN） | — | `isunordered(NaN, 1) = 1` | 用于检测 NaN 参与的比较 |
