# 介绍
CMake 是一个用于管理源代码构建的工具。最初，CMake 被设计为各种 `Makefile` 方言的生成器，如今它还可以生成现代的构建系统，如 `Ninja`，以及 Visual Studio 和 Xcode 等集成开发环境（IDE）的项目文件。 

CMake 广泛用于 C 和 C++ 语言，但它也可以用于构建其他语言的源代码。 

初次接触 CMake 的人可能会有不同的初始目标。如果你想学习如何构建从互联网上下载的源代码包，可以从[用户交互指南](#guide:User_Interaction_Guide)开始。该指南将详细介绍运行 [cmake(1)](#manual:cmake(1)) 或 [cmake-gui(1)](#manual:cmake-gui(1)) 可执行文件所需的步骤，如何选择生成器，以及如何完成构建。 

[使用依赖关系指南](#guide:Using_Dependencies_Guide)面向开始使用第三方库的开发者。 

对于使用 CMake 开始新项目的开发者来说，[CMake 教程](#Guide:Cmake_Tutorial)是一个合适的起点。[cmake-buildsystem(7)](#manual:cmake-buildsystem(7)) 手册面向希望扩展构建系统维护知识的开发者，帮助他们熟悉 CMake 中可以表示的构建目标。[cmake-packages(7)](#manual:cmake-packages(7)) 手册则解释了如何创建可以轻松被第三方基于 CMake 的构建系统使用的软件包。
