根据VS Code官方文档，`launch.json`、`settings.json`、`tasks.json`可用的内置变量分为**预定义变量**和**动态变量**两大类。完整列表如下：

# 预定义变量（Predefined Variables）

这些变量在调试启动时由 VS Code 自动替换为对应的值。

| 变量                             | 含义                                                       |
| :------------------------------- | :--------------------------------------------------------- |
| **`${userHome}`**                | 当前用户的主目录路径                                       |
| **`${workspaceFolder}`**         | 在 VS Code 中打开的工作区根目录的完整路径                  |
| **`${workspaceFolderBasename}`** | 工作区文件夹的名称（不含路径分隔符）                       |
| **`${file}`**                    | 当前在编辑器中激活的文件的绝对路径                         |
| **`${fileWorkspaceFolder}`**     | 当前文件所属的工作区文件夹路径                             |
| **`${relativeFile}`**            | 当前文件相对于 `workspaceFolder` 的路径                    |
| **`${relativeFileDirname}`**     | 当前文件所在目录相对于 `workspaceFolder` 的路径            |
| **`${fileBasename}`**            | 当前文件的文件名（含扩展名）                               |
| **`${fileBasenameNoExtension}`** | 当前文件的文件名（不含扩展名）                             |
| **`${fileExtname}`**             | 当前文件的扩展名（如 `.py`）                               |
| **`${fileDirname}`**             | 当前文件所在的目录路径                                     |
| **`${fileDirnameBasename}`**     | 当前文件所在目录的名称                                     |
| **`${cwd}`**                     | VS Code 启动时任务运行器的当前工作目录                     |
| **`${lineNumber}`**              | 当前光标所在的行号                                         |
| **`${columnNumber}`**            | 当前光标所在的列号                                         |
| **`${selectedText}`**            | 当前编辑器中选中的文本                                     |
| **`${execPath}`**                | 正在运行的 VS Code 可执行文件的路径                        |
| **`${defaultBuildTask}`**        | 默认生成任务的名称                                         |
| **`${pathSeparator}`**           | 操作系统的路径分隔符（Windows 为 `\`，Linux/macOS 为 `/`） |
| **`${/}`**                       | `${pathSeparator}` 的简写形式，可以根据os自动适配"/"和"\\" |

> **提示**：在 `launch.json` 的字符串值中输入 `${` 时，VS Code 的 IntelliSense 会自动弹出完整变量列表。



# 动态变量（Dynamic Variables）

除了预定义变量，VS Code 还支持多种动态解析的变量：

## 环境变量
使用 **`${env:变量名}`** 语法引用系统环境变量。
```json
"args": ["${env:USERNAME}"]
```
*（你之前用过的 `${env:USERNAME}` 就是这种用法）*

## 配置变量
使用 **`${config:设置项ID}`** 引用 VS Code 设置中的值。 
```json
"cwd": "${config:python.defaultInterpreterPath}"
```
>注意：可以在`settings.json`中自定义配置，然后进行引用。
## 命令变量
使用 **`${command:命令ID}`** 执行任意 VS Code 命令，并将其返回值作为变量。**命令必须返回字符串**，否则替换不会完成。
```json
"python": "${command:python.interpreterPath}"
```
*（你之前用过的 `python.interpreterPath` 就是典型的命令变量）*

## 输入变量
使用 **`${input:变量ID}`** 在启动调试时弹出交互式输入框，让用户手动输入或选择值。需要在 `launch.json` 的 `inputs` 数组中定义。

`id`: 一个唯一的字符串，用于在其他地方通过 `${input:你的ID}` 来引用这个输入变量的结果。
`type`: 输入变了类型。取值如下：
- `promptString`：弹出输入框获取字符串（可设置 `password: true` 隐藏输入）
  - `default`：默认值。输入框弹出时，里面预先填好的文本。用户可以保留，也可以直接删掉重写。
  - `description`：提示信息。显示在输入框上方，告诉用户“你需要输入什么”。
  - `password`：密码模式。填 `true` 时，你输入的字符会变成星号 `***`（防偷窥）；填 `false` 或不填，就是正常明文显示。
- `pickString`：弹出下拉选择列表
  - `default`：默认选中项。如果不填，默认选第一项。注意：这个值必须是 `options` 数组中存在的值。
  - `description`：提示信息。显示在下拉框上方，告诉用户“你在选什么”。
  - `options`：选项列表。
    - 字符串数组
    - `{"label":"显示的文字", "value:"实际传递的值"}`数组。
- `command`：执行任意命令获取结果
  - `args`：传递给命令的参数。根据命令的不同，可以是对象、数组或字符串，用于控制命令的行为。
  - `command`: 要执行的命令ID。填写 VS Code 内部命令的标识符
   
 

```json
{
    "version": "0.2.0",
    "inputs": [
        {
            // 1. 定义变量ID，后续通过 ${input:envSelect} 引用
            "id": "envSelect",
            // 2. 类型为 command，表示值来自命令返回值
            "type": "command",
            // 3. 指定要执行的命令（这里使用 Command Variable 扩展提供的命令）
            "command": "extension.commandvariable.pickStringRemember",
            // 4. 传递给命令的参数，用于定义选项列表
            "args": {
                "description": "请选择运行环境",
                "key": "env-config",
                "options": [
                    { "label": "开发环境", "value": "dev" },
                    { "label": "生产环境", "value": "prod" }
                ]
            }
        },
        {
            "id": "envSelect",
            "type": "pickString",
            "description": "请选择要调试的运行环境：",
            "default": "dev",
            "options": [
                "dev", 
                "test", 
                "prod",
                { "label": "开发环境 (Dev)", "value": "dev" },
                { "label": "生产环境 (Prod) - 危险！", "value": "prod"}
            ]
        }
    ]
}
```

# 几个重要注意事项

1. **`${workspaceRoot}` 已废弃**：应改用 **`${workspaceFolder}`**，以更好地支持多根工作区。
2. **变量不能相互依赖**：变量替换是两阶段过程，第一阶段先求值所有变量，第二阶段再做替换。因此一个变量的求值过程**无法访问**其他已被替换的变量。
3. **变量替换不会自动加引号**：如果变量值（如路径）包含空格，需要在 `args` 数组中将整个表达式作为一个独立的字符串元素。
4. **多根工作区限定作用域**：可以通过 `${workspaceFolder:文件夹名}` 的方式引用其他根文件夹的路径。
5. **`tasks.json` 中仅部分字段支持变量**：只有 `command`、`args` 和 `options` 支持变量替换。
